# Ovora Labs Website

Premium research-grade peptides website for **Ovora Labs**, modeled after the Amino Club research-use experience and rebranded throughout.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 4

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Key pages

- `/` — Homepage
- `/research-use` — Research Use Only (primary reference page)
- `/store` — Product catalog
- `/products/[slug]` — Product detail
- `/membership`, `/partners`, `/contact`, `/faq`, `/shipping`, `/quality`, `/coa`, `/research`
- `/disclaimer`, `/terms`, `/privacy`, `/returns`

All products are presented as research-use only.
